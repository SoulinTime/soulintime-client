# Receipts

Permanent public receipts SoulInTime owns. Each line: title, block, SHA-256, receipt URL. Check any of them with `curl -s "https://soulintime.com/functions/v1Verify?hash=<hash>"` or in a browser at https://soulintime.com/check. A receipt shows these exact bytes existed by that block. It does not prove truth or authorship.
