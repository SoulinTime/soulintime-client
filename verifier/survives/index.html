The receipt survives us

This page verifies a SoulInTime statement with no SoulInTime server. Everything it needs is inside this file or in files you pick. It makes no request to soulintime.com. Save it (or open it from the repo), block the domain, and run it.

Spec: sit-statement/0.1 (also hosted at soulintime.com/sit-statement-0.1.md while we exist). Signing key 0a64aa45b8ce17a7, built in below.

What it checks

  1. The statement has exactly the sit-statement/0.1 fields.
  2. The Ed25519 signature over the JCS (RFC 8785) form of every field but sig matches the built-in public key.
  3. sha256 of the .ots equals ots_sha256, and the .ots commits to the statement's sha256.
  4. Replaying the .ots operations from that hash reaches a Bitcoin attestation at block_height. It prints the merkle root that block must have.
  5. Optional: sha256 of your original file equals the statement's sha256.

The last step is yours: compare the printed merkle root with block N on any block explorer or your own node. That is the only outside fact, and it comes from Bitcoin, not from us. A statement says only that these exact bytes existed by that block: not who made them, not that they are true.
