# Reply templates and forwardable note

These are the only outreach texts we use until the first payment and the first outside check of the whitepaper receipt.

Rules:
- Every text uses one link: https://soulintime.com/check
- Every text uses the exact line: these exact bytes existed by this Bitcoin block. Never anything stronger.
- At most two replies a day, only in an existing thread where someone already asks how to prove or check that a file existed. No new posts.
- Say that we run the site. Never post payment details, keys or private emails.

| File | Use it when |
|---|---|
| [bitcoin-ots.md](bitcoin-ots.md) | A Bitcoin or OpenTimestamps thread asks how to check a proof |
| [agent-tool-builder.md](agent-tool-builder.md) | An agent, MCP or tool-builder thread asks how a tool should cite a timestamp |
| [professional-document.md](professional-document.md) | A legal, journalism or business thread asks how to show a document existed |
| [forwardable-note.md](forwardable-note.md) | One person forwards it to another person |
| [scorecard.md](scorecard.md) | Weekly and in every closeout |
